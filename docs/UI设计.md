# UI 设计

> 与 [README.md](../README.md) 中的产品定位对齐。本文档定义视觉规范与页面原型,作为 Flutter UI 实现的参照基准。

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| 简洁 | 信息密度低,核心交互(输入、阅读对话)放在视觉中心 |
| 即时 | 流式响应可视化(打字指示、逐字显示),让用户感到"正在被听见" |
| 可控 | 配置项暴露但不打扰(藏在设置页),常用操作一手可达 |
| 一致 | Material 3 设计语言;暗色 / 浅色主题完全对称 |

## 2. 视觉规范

### 2.1 主题

- **基础**:Material 3 (`useMaterial3: true`)
- **配色**(亮色主题):
  - `primary`:`#1F6FEB`(蓝紫,代表智能)
  - `surface`:`#FFFFFF`
  - `onSurface`:`#1A1A1A`
  - `surfaceContainerLow`:`#F5F7FA`(输入框背景)
  - `userBubble`:`#1F6FEB`(用户消息气泡)
  - `aiBubble`:`#EEF1F6`(AI 消息气泡)
- **暗色主题**:
  - `primary`:`#7AA7FF`
  - `surface`:`#121417`
  - `onSurface`:`#E8E8E8`
  - `surfaceContainerLow`:`#1E2127`
  - `userBubble`:`#2E5BBA`
  - `aiBubble`:`#262A31`

### 2.2 字体

- 中文:`PingFang SC` / `HarmonyOS Sans` / 系统默认
- 西文:`Inter`(备选 `SF Pro Display`)
- 字号刻度:`12 / 14 / 16 / 18 / 22 / 28`

### 2.3 间距与圆角

- 间距单位:`4 / 8 / 12 / 16 / 24 / 32`
- 卡片圆角:`12px`
- 气泡圆角:`16px`(贴边一侧 `4px`,形成"对话气泡"形态)

## 3. 页面清单

```
┌─ 启动 ──────────────┐
│                      │
│   (路由)             │
│                      │
├──────────────────────┤
│ SplashPage           │  启动页:初始化配置、检查 .vex 目录
│         ↓            │
│ HomePage             │  主页(对话历史列表)
│         ↓            │
│ ChatPage             │  对话页(核心交互)
│         ↓            │
│ SettingsPage         │  设置页(模型配置 / 应用配置)
└──────────────────────┘
```

### 3.1 SplashPage(启动页)

- 屏幕中央:应用 Logo + 名称 "灵枭"
- 下方:进度指示(初始化数据库、加载配置)
- 完成后:无历史 → 直接进入 ChatPage(新建会话);有历史 → HomePage

### 3.2 HomePage(主页,对话列表)

```
┌──────────────────────────────────┐
│  灵枭                  ⚙️   │  ← AppBar:标题 + 设置入口
├──────────────────────────────────┤
│  搜索框(可选,v1.1)              │
├──────────────────────────────────┤
│  ┌────────────────────────────┐  │
│  │ Flutter 中的状态管理         │  │  ← 对话卡片
│  │ 今天聊聊 Provider 与...     │  │     标题(可编辑)
│  │ 2 条消息 · 12 分钟前       │  │     最后消息预览
│  └────────────────────────────┘  │     元数据
│  ┌────────────────────────────┐  │
│  │ Android 16KB 页面大小适配   │  │
│  │ 已用 NDK r28 重新打包...    │  │
│  │ 5 条消息 · 昨天             │  │
│  └────────────────────────────┘  │
│                                  │
│                       ⊕ 新建对话 │  ← FAB
└──────────────────────────────────┘
```

**交互**:
- 点击卡片 → 进入 ChatPage(加载历史)
- 长按卡片 → 弹操作菜单:重命名 / 删除 / 导出
- 右滑卡片 → 快速删除(Undo Snackbar)
- 点击 FAB → 进入 ChatPage(新建会话)

### 3.3 ChatPage(对话页,核心)

```
┌──────────────────────────────────┐
│  ← Flutter 状态管理      ⋯     │  ← AppBar:返回 + 会话标题 + 更多
├──────────────────────────────────┤
│                                  │
│  [AI 气泡]                       │
│  你好,我是 灵枭。我可以...     │  ← 左对齐,灰色气泡
│                                  │
│              [用户气泡]           │
│              Provider 怎么用?     │  ← 右对齐,蓝色气泡
│                                  │
│  [AI 气泡 - 流式]                │
│  Provider 是 Flutter ▎           │  ← 打字光标闪烁
│                                  │
├──────────────────────────────────┤
│  [📎]  输入消息...        [➤]  │  ← 输入区
└──────────────────────────────────┘
```

**布局要点**:

- 消息区:`ListView.builder` 反向滚动(底部追加),`padding: 16/12`
- 用户气泡:`alignment: end`,`maxWidth: 75%`,圆角左下 `4px`、其他 `16px`
- AI 气泡:`alignment: start`,`maxWidth: 80%`,圆角右下 `4px`、其他 `16px`
- 思考指示:三圆点动画 + "正在思考..."
- 错误态:红色 ⚠ + "重试"按钮
- 输入框:
  - 多行 `TextField`,`minLines: 1`、`maxLines: 6`,自动扩展
  - 发送按钮:空文本时禁用(灰)
  - 长按输入:粘贴 / 清空

**更多菜单(`⋯`)**:
- 清空对话
- 重命名会话
- 导出 Markdown
- 查看元数据(`conversationId` / 轮次 / token 用量)

## 4. 关键交互流程

### 4.1 发送消息(流式响应)

```
用户输入 → ChatPage 校验非空
       ↓
新建 round += 1 → UI 立刻显示用户消息
       ↓
UI 显示"AI 正在输入"指示
       ↓
ChatRepository.send(conversation, userMsg, history)
       ↓
StreamingProvider.stream(request)  ← 流
       ↓
每收到 chunk → AI 气泡追加 + 滚动到底部
       ↓
流结束 → Agent 抛出 ConversationCompletedEvent
       ↓
HistoryRepository.persist(event)    ← 写入 SQLite
       ↓
UI 隐藏"正在输入"指示
```

### 4.2 启动加载

```
App 启动 → SplashPage
        ↓
ConfigService.init()
  ├─ 检查 <root>/.vex/ 目录是否存在 → 不存在则创建
  ├─ 读取 owl_setting.json → 不存在则写入默认
  └─ 解析 → OwlConfig(provider/model/apiKey/baseUrl)
        ↓
DatabaseService.init()
  └─ Drift 打开 SQLite + 运行 migrations
        ↓
路由决策:
  ├─ 首次启动(无历史) → ChatPage
  └─ 否则 → HomePage
```

### 4.3 配置错误兜底

```
保存配置 → ConfigService.validate()
        ├─ 缺 apiKey → SnackBar 错误,不写盘
        ├─ baseUrl 不合法 → SnackBar 错误
        └─ 通过 → 写盘 + SnackBar 成功

发送消息时若 401/403
  → AI 气泡显示"鉴权失败,请到设置页检查 API Key"
  → 不重试,等用户主动处理
```

## 5. 可访问性(无障碍)

- 所有可点击元素至少 `48x48` 触控区
- 颜色对比度 ≥ WCAG AA(正文 4.5:1,大字体 3:1)
- 文本字号跟随系统设置(`MediaQuery.textScaleFactor` 不锁定)
- AI 消息支持 TalkBack 朗读
